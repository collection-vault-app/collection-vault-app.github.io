Private Google Drive synchronization

Owner-only folder required. Automatic synchronization is opt-in and runs only while the app is open, authorized and not editing. Snapshots are immutable; changes from another device pause uploads until reviewed. Files are not encrypted by Collection Vault.

Connect another device / reconcile changes

On your phone, sync first. On a computer, open the same hosted app, enter the same OAuth client ID, authorize the same Google account and select the same private Vault folder. Then check the latest snapshot. Nothing is pulled or overwritten automatically.
