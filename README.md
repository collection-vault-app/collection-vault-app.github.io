# Collection Vault v0.9.9.8 — Mobile usability pilot

Upload all six application files in this folder directly to the existing collection-vault-app.github.io repository root. README.md is optional. The existing encrypted.html URL, manifest identity and database are unchanged. Do not remove the installed app or clear website data. Before updating, keep an independent encrypted backup of any test data you want to retain. Close the app and any Safari tabs at this origin, commit the replacement files, then reopen online. An old service worker may initially serve the previous version: while locked, use Prepare offline app, close all vault windows, reopen online and confirm v0.9.9.8 in Device setup & offline readiness.

Changes: five-screen navigation, prominent Scan Barcode, basic add form with expandable fields, local video CSP permission, explicit camera state/errors and simulated permission-transition handling. Standard encrypted mode defaults to 60-second background grace (configurable in Settings, capped by inactivity timeout). Keys remain in memory during grace; the visual cover is best effort, not a guarantee against OS snapshots. High Security remains immediate lock, including background permission events; physical camera compatibility is unverified. Page unload, manual lock, credential changes, freeze and expired sessions retain original locks. No database schema, crypto, purge or archive format changes. The root index.html links to encrypted.html; it is not the standard catalog.

Tests: JS syntax and script/worker SHA-256 hashes; Chromium simulated mobile navigation, basic/advanced controls, no horizontal overflow, simulated camera permission hide/show using a canvas MediaStream, track shutdown, high-security zero grace, lock hiding inventory. Actual secure-context navigation blocked in test environment. iPhone permission/camera, persistent database, update behavior and offline operation must be retested. No real inventory yet. Automatic online identification and independent TOTP enforcement are not implemented. Existing standalone recovery tool is unchanged; keep it on your computer.
