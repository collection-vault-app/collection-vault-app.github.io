# Collection Vault v0.9.9.8.1 — Camera troubleshooting pilot

Upload all files in this folder to the existing GitHub Pages repository root. No database migration. Lock and close all app/site tabs after preparing offline app online; reopen and verify version 0.9.9.8.1 under Device setup. Do not uninstall or clear storage.

Scan now offers native photo capture and photo import above optional live camera, with permission/stream/preview stages, timeouts, late-stream cleanup and local photo result feedback. Photo picker may lock the vault if the configured background or inactivity policy expires; use ordinary Camera then import if needed. No credential or encryption changes.

The WebKit standalone-camera problem is not confirmed on the physical iPhone; this is a troubleshooting build, not a verified camera fix. Keep fictional inventory only.

Camera reference: Valley Star Scout (jkramer-cloud/valley-star-scout, upgrade.js) uses getUserMedia with rear camera, ideal 1280x720, no audio, and a muted autoplay playsinline video. This build matches those settings while retaining session epoch, expiry, cancellation and visibility protections. The apps use different origins and security lifecycles; the cause of black video on the physical phone remains unconfirmed.
